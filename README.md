# GoldenDaughter FrontEnd

금딸 기록 및 위기 대응 웹앱 **GoldenDaughter**의 모바일 우선 React PWA입니다.

- React
- Vite 8
- React Router
- Axios
- PWA
- Netlify 배포 기준

## 핵심 화면

- 로그인 / 회원가입
- Home: DAY 카운터 + 랜덤 명언
- Crisis: 위기 기록 + 랜덤 추천글
- Calendar: 일일 체크인
- Statistics: 개인 기록 통계

자세한 실행/배포 방법은 구현 커밋 후 이 문서에 함께 포함됩니다.
